# 🍅 Pomodoro Study App

A simple and student-friendly **Pomodoro Study App** developed as a **Third Year BCA Major Project**.

The application is designed to help students improve their focus, manage study sessions, track their study time, and build consistent study habits using the Pomodoro technique.

* **Yogeshwari Bhosale**
* **Purva Khillare**

## 🎯 Project Objective

Many students find it difficult to concentrate for long periods of time while studying. This application provides a simple way to divide study time into focused sessions and short breaks.

The main goal of the project is to help students:

* Improve concentration
* Develop consistent study habits
* Manage study tasks
* Track completed study sessions
* Set daily study goals
* Take regular breaks

## ✨ Features

### ⏱️ Pomodoro Timer

* Classic Pomodoro timer
* Focus sessions and automatic breaks
* Start, pause, resume and reset controls
* Automatic transition between focus and break sessions

### ⚙️ Custom Timer

* Customize focus duration
* Customize short break duration
* Customize long break duration
* Configure the number of sessions

### ✅ Study Tasks

* Add study tasks
* Delete tasks
* Mark tasks as completed
* Select a task for a study session

### 📊 Session Tracking

* Track completed focus sessions
* Track total study time
* View recent study sessions
* Monitor daily study activity

### 🔔 Notifications

* Notifications when focus sessions end
* Notifications when breaks start/end
* In-app alerts for important timer events

### 🎯 Daily Goals

* Set a daily study-time target
* Track progress toward the goal
* View completed and remaining study time
